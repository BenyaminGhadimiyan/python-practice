# Python Practice

A collection of simple beginner Python projects I built while learning programming. This is the foundation for my journey into Artificial Intelligence.

## Projects

| File | Description |
|------|-------------|
| `calculator.py` | Calculator for `+ - * /` with input validation, division-by-zero handling, and a continue/exit loop |
| `bmi_calculator.py` | Calculates BMI from weight (kg) and height (m) and shows the category |
| `restaurant_menu.py` | Choose items from a menu, build an order, and see the total price |
| `student_grades.py` | Reads 5 students' grades (0-20), calculates the class average, and saves the results to `students.txt` |

## Requirements

- Python 3.10 or newer (`calculator.py` uses `match`)

## How to Run

```
git clone https://github.com/BenyaminGhadimiyan/python-practice.git
cd python-practice
python calculator.py
```

Replace `calculator.py` with any other file to run that project.
